# Scanu v0.1.0 for Windows (preview)

The first Windows build of Scanu, endpoint protection that **freezes threats first and asks you second**.

## Download

**`Scanu_0.1.0_x64-setup.exe`**: installs the Scanu tray app and the **Scanu Sensor** Windows service.
Verify the download against `SHA256SUMS.txt`:

```powershell
(Get-FileHash .\Scanu_0.1.0_x64-setup.exe -Algorithm SHA256).Hash.ToLower()
```

**Requirements:** Windows 10 (21H2+) or Windows 11, x64, administrator rights to install. WebView2 is installed automatically if it's missing.

> **Unsigned preview build.** Windows SmartScreen will warn about an unknown publisher (**More info → Run anyway**). Code signing comes with a later release.

## What you get

Everything below works **offline, with no account**:

- **Real-time protection:** process, network, DNS and PowerShell telemetry via ETW; Windows Security log monitoring.
- **New-program check:** every new executable is hashed and scored by the on-device model as it starts. Known-bad programs are frozen immediately (suspended and cut off from the network).
- **Ransomware decoys:** hidden canary files in each user's Documents and Pictures. Anything that writes, renames or deletes one is frozen.
- **Suspicious behaviour alerts:** download-and-execute scripts, random-looking (DGA) domains, DNS tunnelling, beaconing, programs reading browser password stores, mass file modification.
- **Scan this PC:** Quick scan (Downloads, Desktop, Temp, AppData, Startup) or Full system scan (every fixed drive), from the tray app.
- **Threats found:** quarantine flagged files into an encrypted vault (AES-256-GCM, reversible), or stop a program Scanu froze. You can only act on what Scanu flagged; restoring from the vault requires the cloud console in this release.

**Optional: link to a Scanu cloud** for fleet management, AI-assisted incident investigation and approve/rollback workflows. Get an enrollment file from your administrator, then in an elevated prompt:

```powershell
& "C:\Program Files\Scanu\scanu-sensor.exe" enroll .\enrollment.json
```

## Known limitations of this preview

- **No kernel driver yet.** The minifilter needs Microsoft signing first. Until then:
  - new programs are scored *right after* they start, not blocked before;
  - canary writes are seen through ETW (milliseconds, not microseconds), and the write itself isn't denied;
  - the sensor isn't protected against administrators who stop it.
- **No PPL / ELAM** (requires Microsoft Virus Initiative membership).
- **Detection model:** the on-device model is a hand-tuned baseline, so expect some false positives. Frozen programs can be stopped from the app; resuming or allowing them requires the cloud console.
- The device key is stored with DPAPI, not yet in the TPM.

## Uninstall

**Settings → Apps → Scanu → Uninstall** removes the app and the service. `C:\ProgramData\Scanu` (vault and logs) is kept on purpose, so quarantined files aren't lost. Delete it manually if you don't need them.

## Logs

`C:\ProgramData\Scanu\logs\sensor.log` (administrators only).
